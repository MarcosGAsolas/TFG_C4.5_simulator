Entropía Entropía condicional
Información general

En teoría de la información, la entropía es una medida de impureza, incertidumbre o aleatoriedad en un conjunto de datos. En datasets con clases binarias, donde las variables solo pueden tener dos posibles valores de salida, el valor de la entropía está entre 0 y 1, ambos incluidos. Cuanto mayor es la entropía, más impuro es el dataset.

Cálculo

La entropía de un dataset respecto a una variable objetivo o clase se calcula usando la siguiente fórmula:

\(H(X) = - \sum_{i=1}^{n} (p_i \log_2(p_i)) \)

Donde:

  • \(X\) es el dataset
  • \(n\) es el número de clases
  • \(p_i\) es la proporción de instancias (datos o filas) que pertenecen a la clase \(i\)

Función de entropía binaria

Estás usando más de 2 clases. Los resultados no se pueden mostrar en la gráfica de entropía binaria. La gráfica solo representa la curva de entropía para 2 clases.
