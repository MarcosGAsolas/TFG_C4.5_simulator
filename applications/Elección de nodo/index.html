Elección de nodos

La Elección de Nodos se consigue determinando que subconjunto del conjunto que estamos analizando tiene El Gain Ratio más alto, para poder elegir de entre una cantidad de subconjuntos x, el mejor candidato y seguir formando nuestro arbol de desision.

Tenemos este dataset inicial de ejemplo para ver cómo se selecciona un nodo dentro de este dataset y poder explicar de manera adecuada el algoritmo. Para emepezar, tenemos que elegír un umbral para poder ver la entropia de las clases.

El umbral se calcula para poder agrupar datos y poder seccionar el subconjunto y calcular la entropia del subconjunto, el primer paso para ello, es ordenar de menor a mayor el subconjunto del que queremos calcular la entropia, en este caso, vamos a explicar el cálculo del gain ratio solo con el subconjunto de Horas_estudio.
