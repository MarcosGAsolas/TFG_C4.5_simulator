Simulador del algoritmo C4.5

Este simulador está hecho para que se pueda comprender de manera clara y sin dudas la construcción del árbol de decisión del algoritmo C4.5.
Esta aplicación ofrece una explicación teórica de los conceptos clave para la construcción del árbol. Primero ofrece todo lo necesario para comprender la entropía, posteriormente ofrece todo lo necesario para entender la elección de los nodos en un dataset y por último ofrece una simulación paso a paso de un dataset de ejemplo para ver cómo se construye el árbol.
