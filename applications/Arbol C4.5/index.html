Árbol de decisión C4.5

Información general

El algoritmo C4.5 construye el árbol de decisión de forma recursiva. Para ello, parte de un conjunto de datos inicial \(S\) y de un conjunto de atributos \(A\).

En cada iteración, el algoritmo evalúa cada atributo disponible y calcula las medidas explicadas anteriormente: entropía, ganancia de información, Split Info y Gain Ratio.

El atributo seleccionado como nodo será aquel que obtenga el mayor valor de Gain Ratio, ya que esta medida permite elegir la variable que mejor divide el conjunto de datos penalizando, al mismo tiempo, las divisiones excesivamente ramificadas.

En el caso de los atributos continuos, C4.5 no divide directamente por cada valor diferente del atributo, sino que busca posibles umbrales de división. Cada umbral separa el dataset en dos subconjuntos:

  • ejemplos cuyo valor es menor o igual que el umbral
  • ejemplos cuyo valor es mayor que el umbral

Para cada posible umbral se calcula el Gain Ratio y se selecciona aquel que produzca la mejor división.

El proceso continúa de forma recursiva sobre cada subconjunto generado, creando nuevos nodos y ramas hasta que se cumple alguna condición de parada:

  • todos los ejemplos de un subconjunto pertenecen a la misma clase
  • no quedan atributos disponibles para dividir
  • no existe una división que mejore la clasificación de los datos

En estos casos, el algoritmo crea un nodo hoja, asignando normalmente la clase mayoritaria del subconjunto.

Algoritmo C4.5

Entrada:

  • Dataset \(S\)
  • Conjunto de atributos \(A\)

Salida:

  • Árbol de decisión \(T\)

Algoritmo:

  1. Ejecutar \(\operatorname{C4.5}(S, A)\), donde \(S\) representa el nodo actual del árbol \(T\).
  2. Comprobar si \(S = \varnothing\):
    • Si se cumple, crear una hoja con la clase mayoritaria del nodo anterior y devolverla como \(T\).
  3. Comprobar si todos los ejemplos de \(S\) pertenecen a la misma clase \(c\):
    • Si se cumple, crear una hoja con la etiqueta \(c\) y devolverla como \(T\).
  4. Comprobar si el conjunto de atributos \(A\) está vacío:
    • Si se cumple, crear una hoja con la clase mayoritaria de \(S\) y devolverla como \(T\).
  5. Para cada atributo \(a \in A\), calcular sus posibles particiones:
    • Si \(a\) es continuo, generar umbrales \(u\) y dividir \(S\) en \(S_{\leq u}\) y \(S_{>u}\).
    • Si \(a\) es categórico, dividir \(S\) según los valores de \(a\).
  6. Para cada partición, calcular \(\operatorname{Gain}(S,a)\), \(\operatorname{SplitInfo}(S,a)\) y \(\operatorname{GainRatio}(S,a)\).
  7. Seleccionar \(a_{\text{mejor}}\) como el atributo con mayor \(\operatorname{GainRatio}\). Si el atributo es continuo, conservar también el mejor umbral \(u_{\text{mejor}}\).
  8. Crear un nodo de decisión con \(a_{\text{mejor}}\).
  9. Si \(a_{\text{mejor}}\) es continuo, crear dos ramas:
    • Rama izquierda: \(\operatorname{C4.5}(S_{\leq u_{\text{mejor}}}, A)\)
    • Rama derecha: \(\operatorname{C4.5}(S_{>u_{\text{mejor}}}, A)\)
  10. Si \(a_{\text{mejor}}\) es categórico, para cada valor \(v \in \operatorname{Values}(a_{\text{mejor}})\), crear \(S_v\):
    • Si \(S_v = \varnothing\), añadir una hoja con la clase mayoritaria de \(S\).
    • Si \(S_v \neq \varnothing\), añadir como rama \(\operatorname{C4.5}(S_v, A - \{a_{\text{mejor}}\})\).
  11. Aplicar poda posterior al árbol generado y devolver el nodo de decisión.

Requisitos del archivo
  1. Formato: archivo CSV separado por comas.
  2. Cabecera: la primera fila debe contener los atributos.
  3. Filas: el dataset no puede tener más de 150 filas de datos.
  4. Columnas: el dataset no puede tener más de 25 columnas.
  5. Cabecera completa: la cabecera no puede contener columnas vacías.
  6. Filas: todas las filas deben tener el mismo número de columnas.
  7. Valores: no puede haber valores vacíos.
  8. Formato de columnas: cada columna debe tener todos los datos del mismo formato.
  9. Formatos permitidos: los datos pueden ser numéricos, booleanos o categóricos.
  10. Clase: la última columna debe ser la clase objetivo.
  11. Valores de clase: la última columna debe contener exactamente dos valores distintos.
